# ART SYSTEMA — сайт-каталог подвесных систем для картин

Многостраничный сайт с каталогом, корзиной-заявкой и собственной админкой, в которой правится **весь** текст сайта — без разработчика и без пересборки.

Разработан с нуля: своя вёрстка, свои компоненты, своя админка. Шаблоны и конструкторы не использовались.

---

## Стек

**Фронтенд и бэкенд — один проект на Node.js.** PHP, Python и база данных не используются.

| Что | Версия |
|---|---|
| TypeScript | 5.7 |
| Next.js | 15, App Router, сборка `standalone` |
| React | 19 |
| Tailwind CSS | 4 |
| framer-motion | 12 |
| lucide-react | 0.475 |
| next-themes | 0.4 |
| Node.js | 20+ |

Внешний сервис один — [Web3Forms](https://web3forms.com) для отправки заявок с формы.

---

## Что внутри

- 7 страниц: главная, каталог, услуги, работы, доставка и оплата, о компании, контакты, плюс политика конфиденциальности
- каталог: 37 товаров, 68 вариантов с ценами, 3 категории, фильтр
- корзина: посетитель собирает спецификацию и отправляет одной заявкой
- формы заявки в четырёх местах, включая модальное окно и первый экран
- админка: правка всего контента, цен, товаров, загрузка фото
- светлая и тёмная тема, адаптив от 320 px, WhatsApp-кнопка, нижняя панель действий на мобильных
- SEO: метаданные, Open Graph, генерация `sitemap.xml` и `robots.txt`

Вес страницы — 0,76 МБ.

## Запуск

```bash
npm install
cp .env.example .env.local   # заполнить значения
npm run dev                  # http://localhost:3300, админка на /admin
```

Переменные окружения:

| Переменная | Назначение |
|---|---|
| `ADMIN_PASSWORD` | пароль входа в админку |
| `ADMIN_SECRET` | секрет подписи сессионной cookie |
| `NEXT_PUBLIC_WEB3FORMS_KEY` | ключ сервиса отправки заявок |
| `CONTENT_DIR` | папка с `site.json` и `catalog.json` (по умолчанию `./content`) |
| `UPLOAD_DIR` | папка с загруженными фото |
| `NEXT_PUBLIC_BASE_PATH` | подпапка, если сайт не в корне домена |
| `NEXT_PUBLIC_SITE_URL` | адрес сайта для sitemap и robots |

Последние две вшиваются при сборке.

## Сборка и выкладка

```bash
rm -rf .next
NEXT_PUBLIC_SITE_URL=https://домен-заказчика.ru npx next build

cp -r .next/static .next/standalone/.next/
cp -r public content .next/standalone/
node .next/standalone/server.js
```

Полная инструкция по выкладке, устройство сервера, systemd-юнит и описанные грабли — в [HANDOVER.md](HANDOVER.md).

### Требования к хостингу

- VPS или хостинг с поддержкой Node.js 20+ (шаред-хостинг «для WordPress» не подойдёт)
- 512 МБ памяти достаточно, комфортно 1 ГБ
- nginx как реверс-прокси на порт приложения
- сертификат Let's Encrypt
- база данных не нужна

**Важно:** папки `CONTENT_DIR` и `UPLOAD_DIR` должны лежать **вне** каталога с кодом, иначе выкладка новой версии сотрёт всё, что заказчик наредактировал через админку.

## Что нужно доделать перед боевым запуском

1. Завести ключ Web3Forms на почту заказчика — сейчас заявки уходят на ящик разработчика.
2. Подключить домен и HTTPS; убрать `NEXT_PUBLIC_BASE_PATH`, чтобы сайт открывался в корне домена.
3. Подключить Яндекс.Метрику.
4. Сменить пароль админки и передать заказчику.
